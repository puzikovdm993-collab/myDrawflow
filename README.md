# myDrawflow

Веб-приложение для построения workflow схем на базе библиотеки Drawflow.

## 🚀 Возможности

- **Визуальный редактор** - перетаскивание узлов и создание связей
- **4 типа узлов**:
  - 🚀 Старт - начальный узел workflow
  - ⚙️ Процесс - обычный процесс/действие
  - ❓ Решение - узел с ветвлением (2 выхода)
  - 🏁 Финиш - завершающий узел
- **Drag & Drop** - добавление узлов перетаскиванием из панели
- **Редактирование свойств** - изменение названий узлов
- **Сохранение/Загрузка** - экспорт в JSON и импорт обратно
- **Горячие клавиши**:
  - `Ctrl+S` - сохранить workflow
  - `Ctrl+L` - загрузить workflow
  - `Delete/Backspace` - удалить выбранный узел
  - `Escape` - закрыть модальное окно

## 🛠️ Запуск

Просто откройте файл `index.html` в любом современном браузере.

Или используйте локальный сервер:

```bash
# Python 3
python -m http.server 8000

# Node.js (если установлен http-server)
npx http-server -p 8000
```

Затем откройте в браузере: `http://localhost:8000`

## 💡 Как использовать

1. **Добавить узел**:
   - Перетащите тип узла из левой панели на холст
   - Или кликните на тип узла в панели
   - Или нажмите кнопку "➕ Добавить узел"

2. **Создать связь**:
   - Перетащите от выходной точки (справа) одного узла к входной точке (слева) другого

3. **Редактировать узел**:
   - Кликните на узел для выделения
   - Измените название в панели свойств слева

4. **Удалить узел**:
   - Выделите узел и нажмите Delete или кнопку "🗑️ Удалить узел"

5. **Сохранить workflow**:
   - Нажмите "💾 Сохранить" или Ctrl+S
   - Файл скачается и сохранится в localStorage браузера

6. **Загрузить workflow**:
   - Нажмите "📂 Загрузить" или Ctrl+L
   - Загрузится последнее сохранение или можно выбрать JSON файл
